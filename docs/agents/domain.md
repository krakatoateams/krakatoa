# Domain docs

This repository uses a single-context layout.

Before exploring, read `CONTEXT.md` and relevant ADRs under `docs/adr/` when
they exist. Missing files are expected and should not block work.

Use terminology defined in `CONTEXT.md`. If a needed concept is missing,
reconsider the term or record the gap for domain modeling.

Surface any conflict with an existing ADR explicitly rather than silently
overriding it.
