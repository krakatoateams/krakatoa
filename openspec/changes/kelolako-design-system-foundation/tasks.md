Swatches use inline `style={{ backgroundColor }}` rather than Tailwind color classes — the swatch set is fully dynamic (derived from however many keys exist in the config), and Tailwind's build-time class scanner can't discover class names assembled from runtime data, so inline style is the correct (not "hardcoded") way to render a genuinely dynamic list. This is a deliberate departure from Button's approach, where the variant set is small and fixed, so literal classes were used instead (task 3.3).
